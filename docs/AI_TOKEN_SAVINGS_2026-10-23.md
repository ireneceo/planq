### 결정이 필요한 것 (손대지 않음)
- **채팅 업무 자동 추출 사전 검사** `services/taskExtractorScheduler.js` → `task_extractor.js:382` — 원장상 35회 출력 합계 974토큰(회당 약 28) = 거의 전부 `{"tasks":[]}`.
  새 메시지가 전부 맞장구·이모지면 건너뛰는 검사. **추출 판정 조건 변경이라 Fable 설계 대상**(CLAUDE.md «판정 조건·분류 기준»).
- **Q note 답변 생성 시점** — 감지된 질문마다 아무도 안 눌러도 LLM 답을 미리 만든다. 미리는 임베딩 매칭까지만 하고 생성은 [답변 찾기] 를 눌렀을 때 하면 비용이 크게 준다. 품질은 같고 **누른 뒤 2~3초 늦어진다** — 제품 결정.
- **고객 대화방 Cue 자동 답변** `routes/projects.js:1584` → `cue_orchestrator.js:224` — «감사합니다» 에도 gpt-5.1 로 답을 만든다.
  ① 고정 규칙을 앞으로 + 캐시 키(위험 없음 — 위 6번과 함께 해도 된다) ② 맞장구만 있는 메시지 건너뛰기 = 고객에게 보이는 동작 변경이라 결정 필요.
