## 지금 구조 (`dev-frontend/src/pages/QMail/ThreadMessages.tsx`)
메일 상세 = 최신이 위, 한 스크롤 상자. 펼친 메시지 카드 하나는:
머리(보낸 사람·받은 주소·시간·복사·새 창) → [번역문 — 028e3b69 부터 본문 위에 뜨고 그 자리로 스크롤]
→ 본문(HTML iframe · 이전 대화는 인용 표식이 잡힐 때만 접힘 · 서명) → 첨부 → **번역 줄**(언어 셀렉트 + 번역하기 + 이 메일 확인).
접힌 옛 메시지에는 번역 줄이 없다. 서버는 인용·서명을 뺀 새 부분만 번역한다(번역문은 짧다).

## 선택지
- **A** 번역 줄(언어 + 번역하기 + 이 메일 확인)을 펼친 메시지의 **머리 바로 아래**로 옮긴다. 번역문은 이미 그 바로 밑에 뜬다. 아래 줄은 없앤다.
- **B** 아래 줄은 두고, 메시지 머리 아이콘(복사·새 창 옆)에 번역 아이콘 하나 추가. 언어 바꾸기는 번역문 머리에서.
- **C** 상세 2밴드(메타 밴드)에 스레드 단위 [번역] — 기준 메시지(최신 받은 메일)를 번역.

## Opus 권고 (Fable 판정 전 — 확정 아님)
A. 누를 자리 = 결과가 뜨는 자리 = 읽기 시작하는 자리로 셋이 겹친다. 메시지마다 붙어 «어느 메일 것인지» 가 갈리지 않는다.
C 는 여러 통 중 어느 것을 번역하는지 모호하고, B 는 버튼이 두 벌이 된다.
첨부 순서 계약(첨부는 본문 바로 아래 · `--suite` mail-attach-order 가 «첨부 y < 번역줄 y» 를 잰다)은 A 에서 바뀌므로 그 카나리 판정도 같이 바꿔야 한다 — 이것이 Fable 에게 물을 핵심 중 하나.
