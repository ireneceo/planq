## 고치지 않고 남긴 것 — 정해야 하거나 큰 것
### 매일 시끄러운 것 (높음)
- **채팅 메시지마다 방 참여자 전원에게 메일이 바로 나간다**(종류×채널 설정을 안 건드린 사람은 켜짐). `routes/conversations.js` notifyMany(kind message) → `notify()` 메일 채널 — 건너뛰기 없음. dev 30일 `notify:message` 111건(dev 는 발송 정지라 skipped). 게다가 «5분 안 읽으면 메일» 안전망(`services/unreadEscalationCron.js`, 주석: «자리에 있으면 이메일 스킵 — 스팸 방지»)이 **같은 메시지를 한 번 더** 메일로 보낼 수 있다. 25명 방에서 한 사람이 말할 때마다 24통. → 결정 필요(외부 발송 트리거 = Fable 게이트). 10-07 결정 ⑤ «채팅 메일 묶음» 과 같은 일.
- **방·프로젝트 단위 음소거·방해금지·묶음이 없다**(ORG_SCALE_REVIEW F3 / 1-2 그대로).
- **책임자 없는 회사 메일함은 메일 알림이 멤버 전원에게**(`services/mailNotify.js:118-130`, 기본 «추천») — 확인 필요의 책임자 귀속(11-10)은 알림에는 안 걸린다(`mailTodoWhere.js:12`). 사람별 «메일 주소별 알림» 으로 각자 끌 수는 있다.
- 휴가 신청·근태 정정 알림이 **대표·관리자 전원에게**, 부서장 라우팅 없음(S2 그대로).
- 캘린더는 늘 «전체» 범위 — 사람·팀 필터가 없다(서버 `scope=mine` 은 있는데 화면이 안 씀). 25명 일정 + 업무 마감이 한 달력에 겹친다.

### 대표·관리자가 헷갈리는 것 (중)
- **초대는 대표만** 된다 — 관리자는 참여 신청 승인·권한·조직은 되는데 [멤버 초대] 버튼이 안 보인다. 승격 창 문구(«인사·결제·세금계산서 외 거의 모든 권한»)와도 어긋난다. (권한 변경 = Fable 게이트, 10-22 설계에서 «admin 은 1-3 때» 로 미룸)
- **11번째 사람부터 막힌다**(Pro 10명) — 막힐 때 문구만 있고 요금제 화면 링크가 없다 · 멤버 화면에 «몇 명 / 몇 자리» 가 없다 · 자리 추가는 신청 → 계좌 이체 → **다음 영업일** 반영(즉시 결제 아님).
- 멤버 목록에 **찾기·부서 거르기가 없다**(30줄을 눈으로) · 권한 표는 30명 × 12칸에 머리줄이 고정 안 됨 · 같은 권한을 표와 사람별 창 두 곳에서 고친다.
- «관리자» 가 세 뜻 — 워크스페이스 관리자(admin) · 대표(«마지막 관리자는 제거할 수 없습니다») · 플랫폼 운영자(«관리자에게 문의»). «역할» 도 두 뜻(권한 등급 / 프로젝트 기본 역할).
- 사람 고르는 칸에 **같은 이름을 가를 단서가 없다**(부서·이메일 없음 — 프로젝트 멤버 추가·대화 설정만 이메일) · 머리글자 아바타가 성(김·이·박)이라 다 같아 보인다.
- 휴가 거절에 사유 칸이 없다(서버는 받는다) · 일괄 승인 없음.
- 대화방 «N명 읽음» 만 — 누가 안 읽었는지 못 본다(1-4 «읽음 목록» 그대로).

### 괜찮은 것 (다시 볼 필요 없음)
전사 자동 대화방 없음 · 프로젝트 만들 때 전원 알림 없음 · 업무 알림은 이름 박힌 사람에게만 · 멤버는 참여한 대화방·프로젝트만(11-06·10-16) · 확인 필요의 청구·세금 항목은 대표·관리자만 · 사이드바 근무 현황 목록은 정렬·스크롤 됨.
