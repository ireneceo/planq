## 3. 무엇을 보내나 — «글 한 편 → 채널별 소재 묶음»
링크만 뿌리면 거의 안 퍼진다(LinkedIn·Facebook·Instagram 모두 외부 링크 글의 노출을 깎는다). 한 편을 채널 문법에 맞게 다시 만든다.

| 소재 | 만드는 법 | 쓰는 채널 |
|---|---|---|
| ① 카드뉴스 5~8장 (1080×1350) | AI 가 글을 «한 줄 훅 → 문제 → 핵심 3~5개 → PlanQ 로 푸는 법 → 행동 유도» 로 요약 → **브랜드 템플릿(HTML) → PNG** | Instagram 캐러셀 · LinkedIn 이미지 · Threads · 네이버 |
| ② 채널별 본문 | LinkedIn(첫 2줄 훅·짧은 줄·질문으로 끝·링크는 첫 댓글) · Instagram(캡션 + 해시태그 5~10) · Threads(3~4줄) · 네이버(검색어 제목·소제목·1,500자+) | 각 채널 |
| ③ 글별 링크 미리보기 이미지 (1200×630) | ①과 같은 템플릿 첫 장 | **모든 공유** — 지금 전부 기본 이미지라 이것만으로도 클릭률이 오른다(SNS 없이도 바로 이득) |
| ④ 쇼츠·릴스 30~60초 (1080×1920) | 카드 장면 + 큰 자막 + 배경음(선택: AI 음성). ffmpeg 필요 | YouTube 쇼츠 · 릴스 · LinkedIn 영상 |
| ⑤ 제품 시연 영상 | **자동 생성으로는 품질이 안 나온다** — 실제 화면 녹화 + 사람 목소리. 기능은 «올리면 채널별로 나눠 보내기» 까지 | YouTube |

### 고퀄리티를 만드는 방법 (권고)
1. **AI 는 초안, 사람이 승인.** 틀린 숫자·어색한 문장이 회사 계정에 한 번 나가면 되돌릴 수 없다. 승인이 쌓인 템플릿부터 «자동» 으로 넓힌다.
2. **템플릿 3~4종만 아주 잘** — 문제제기형 · 체크리스트형 · 전후비교형 · 숫자형. 매번 AI 에게 새 디자인을 맡기지 않는다(일관성이 브랜드다). 슬로건 «일을 일답게 하다, PlanQ» · 포인트 색 코랄.
3. **훅이 전부다** — 첫 장/첫 2줄에 «대상 + 고통» («고객 요청이 카톡·메일·엑셀에 흩어져 있다면»). AI 에게 훅 5개를 뽑게 하고 사람이 고른다.
4. **모든 링크에 출처 표시** `utm_source=<채널>&utm_medium=social&utm_campaign=insight_<글>` — 이미 있는 가입 출처·GA4 와 이어져 **어느 채널·어느 글이 가입을 만들었는지** 관리자 화면에 보인다.
5. **한 편을 2주에 걸쳐 나눠 쓴다** — 같은 글을 각도·채널별로 3~4번(«하나씩» 요청과 같은 뜻). 15편이면 주 3회로 약 6주 → **글 공급이 진짜 병목**이다.
6. **성과를 다시 읽어 고친다** — 채널 API 로 노출·반응·클릭을, 우리 DB 로 가입을 모아 «잘 된 템플릿·시간대» 를 다음 소재에 반영.

## 4. 화면 안 (플랫폼 관리자 > SNS 발송 — 새 메뉴)
1. **계정 연결** — 채널 카드마다 [연결]·상태·만료일 + «연결하려면» 안내 단계(비즈니스 계정 전환 · 페이지 관리자 권한 · 앱 심사 상태). 만료 7일 전 관리자 알림.
2. **소재 만들기** — 인사이트 글 목록 → [소재 만들기] → 카드 미리보기·채널별 본문 편집 → [승인·예약]. 네이버·카카오는 [원고 복사]·[이미지 내려받기]·[게시함 표시].
3. **발송 달력·결과** — 예약/보냄/실패(이유) · 채널별 성과 · 글별 가입 수.

## 5. 구조 뼈대 (Fable 설계에서 확정)
- 새 표: `social_accounts`(채널·계정명·암호화 토큰·만료·상태, 플랫폼 공통) · `social_posts`(글·채널·소재·본문·파일·상태 초안→승인→예약→보냄/실패·외부 id·성과) · 발송 기록.
- 서버: 채널 어댑터 한 벌(`services/social/<채널>.js` — 올리기·갱신·성과) · 상태 전이 한 문 · 예약 발송 cron(겹침 방지) · 관리자 전용 OAuth 콜백.
- 공개 이미지 주소: Instagram·Threads 는 이미지를 **공개 주소에서 가져간다** → 추측 불가 이름·기한 있는 공개 경로 필요(공개 표면 추가 = Fable 게이트).

## 6. 단계 (권고 순서)
1. **글별 링크 미리보기 이미지 + 카드뉴스 템플릿** — SNS 연결 없이도 바로 이득, 심사 기다리는 동안 만든다.
2. 관리자 화면 + 승인 흐름 + 네이버/카카오 반자동(심사 불필요).
3. LinkedIn · Meta(Facebook·Instagram·Threads) 자동 발송 — 심사 통과 순서대로 켠다.
4. 쇼츠 자동 생성(ffmpeg) + YouTube.
5. 성과 화면 · 템플릿별 비교.

## 7. 정해야 할 것 (Irene)
1. 채널 1차 묶음 — 권고: LinkedIn 회사 페이지 + Facebook/Instagram + Threads (+ 영상 생기면 YouTube), 네이버 블로그·카카오는 반자동, X·TikTok 보류.
2. 발송 방식 — 권고: AI 초안 → 승인 → 예약 자동 발송. 무인 발송은 승인이 쌓인 템플릿만 나중에.
3. 영상 — 권고: 카드 → 쇼츠 자동 생성(ffmpeg 설치 1회) + 시연 영상은 사람이 녹화해 올리면 나눠 보냄. AI 아바타(외부 유료)는 효과 본 뒤.
4. 글 공급 — 인사이트 글을 주 1편 더 쓰는 계획을 같이 세울지.
