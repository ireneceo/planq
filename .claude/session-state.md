- 또는 `PATCH /api/feedback/:id/respond { status:'done', admin_response }` (platform_admin)

닫고 나면 다음 배포에 반영하거나 `scripts/feedback-close-backlog.txt` 에 번호를 적는다.

## 오늘 배운 것

- **재신고는 "못 고쳤다" 가 아니라 "다른 문으로 들어온다".** #403 은 8/31 에 고쳤는데 9/3 에 다시 왔다.
  업무 상세에만 물음을 달았고 **목록에서 고치는 경로 2곳**은 그대로였다. 판정을 한 파일로 모았다.
- **"큰 개발"이라 답하기 전에 코드를 본다.** #233·#343·#379 를 "큰 3건" 이라고 보고했는데
  셋 다 이미 구현돼 있었다. 운영에 Drive watch 채널이 살아 있고 Drive 유래 파일이 43건이었다.
- **화면 불만은 좌표로 재야 한다.** "셀렉트 글자가 크다" 는 실측 16px 대 주변 13px 이었고,
  "버튼 높이가 다르다" 는 헤더 32 대 44 였다. y 좌표만으로 묶으면 **거짓 24건**이 나온다 —
  같은 부모·가로 인접까지 봐야 진짜 8건이 남는다.
- **가드가 내 주석을 잡았다.** 코드와 같은 줄의 블록 주석 안 따옴표는 제외 규칙을 못 지난다.
  베이스라인을 늘리지 않고 문구를 고쳤다 — 래칫을 올리는 순간 그 자리는 영영 안 보인다.
- **`pkill -f "tsc -b"` 가 방금 띄운 빌드를 죽였다**(exit 144). 정리하고 다시 띄우지 말고, 그냥 다시 띄운다.
- **장부는 트레일러만으로 안 닫힌다** — 답글이 있어야 닫힌다. 사용자에게 무엇을 고쳤는지 말하는 것이 조건이다.
