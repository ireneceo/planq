링크를 눌러도 안드로이드 앱이 안 열린다. 필요한 값:

> Play Console → 테스트 및 릴리스 → 설정 → **앱 서명** → "앱 서명 키 인증서" 의 **SHA-256**

## 오늘 배운 것 (다음 세션이 같은 실수를 안 하도록)

- **★ 신고를 고칠 때 규칙을 바꾸지 마라.** 배지가 "사라진다" 는 신고에 나는 배지의 **정의**를
  알림 수로 갈아치웠다. 요청받은 적 없는 변경이었고, 좌측 메뉴는 2인데 아이콘은 17이 됐다.
  정본은 `3679ce3d` — 인박스 + Q Talk. 고칠 것은 사라지는 현상 하나였다.
  **"전에 열심히 고친 것" 이 있으면 git 으로 그 시점 코드를 먼저 읽는다.**
- **★ 대조군이 없으면 통과를 믿지 마라.** 배지는 가드를 빼고 돌려서야 첫 로드에 `clear` 가
  불리는 것을 봤고, 휴지통은 옛 동작으로 되돌려서야 복원 후 청크 0 을 봤다. 둘 다 대조군
  없이는 "고쳤다" 를 증명할 수 없었다.
- **★ 치환 결과를 확인 없이 출력하지 마라.** python replace 가 조용히 실패했는데 성공 메시지를
  찍어 두 번 헛돌았다(`RETENTION_ROLLOUT_AT` 상수, 헬스체크 SQL). assert 를 걸어라.
- **★ "큰 개발" 이라 답하기 전에 코드를 본다.** #233·#343·#379 를 큰 3건이라 보고했는데
  셋 다 이미 구현돼 있었다. 운영에 Drive watch 채널이 살아 있고 Drive 유래 파일이 43건이었다.
- **★ 장부는 트레일러만으로 안 닫힌다** — 답글이 있어야 닫힌다. 사용자에게 무엇을 고쳤는지
  말하는 것이 조건이다.
- **화면 불만은 좌표로 재라.** "셀렉트 글자가 크다" = 실측 16px 대 주변 13px. y 좌표만으로
  묶으면 거짓 24건이 나온다 — 같은 부모·가로 인접까지 봐야 진짜가 남는다.
- **`paginatedResponse` 는 추가 키를 버렸다.** 호출부가 넘기던 `retention_days` 가 한 번도 나간
  적이 없었다. 만들어 놓고 읽는 곳이 없는 게 아니라 **보내는 쪽에서 조용히 버려졌다.**
- **`pkill -f "tsc -b"` 가 방금 띄운 빌드를 죽인다**(exit 144). 정리하고 다시 띄우지 말고 그냥 다시 띄운다.
