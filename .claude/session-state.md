**글씨 크기 키우기 (Irene 요청) — 배포됨. Fable 설계·구현 게이트 2회 통과**
- 전환 전 실측: rem **0곳**, font-size 전부 px → OS·브라우저 글꼴 설정이 이 앱에만 안 먹었다.
  모바일 렌더 769개 중 ≤11px 26.9% / ≤13px 62.5% / 크기 20종 이상.
- px→rem **4,022곳 / 314파일** + 루트 배율 + 설정 3단(**기기별** localStorage).
  검증: 13화면 · 텍스트 11,363개 · **비교 22,726쌍 0오차** · 1.3× 가로스크롤 0.
- 세트: viewport `maximum-scale` 제거 + 폰 입력칸 16px(24화면·모달 24개·입력칸 124개 전부 ≥16px).
- 가드 **fontpx** 신설(베이스 0 fail-closed, 5형태 각각 반증).
- ★Fable 이 **배포 차단 조건**으로 입력칸 구멍 2개를 잡았다 — textarea/select 특이도 패배 +
  react-select 인라인 `font: inherit`. 그대로 배포했으면 iOS 자동확대 회귀가 살아났다.

**#383 Q Note 녹음파일 업로드 — 배포됨. 운영 실동작 확인**
- 아이폰 m4a 25분 → **9초에 378 발화** 전사. 과금 원장 정확히 1건, 같은 키 재전송 멱등 확인.
- ★"ffmpeg 이 없어 못 한다" 던 진단이 **절반 틀렸다** — mutagen(순수 파이썬)이 m4a 헤더를 읽는다.
- ★**파이썬 의존성이 운영에 영영 설치되지 않던 것** 발견 — 배포 스크립트가 `if [ ! -d venv ]` 라
  첫 배포에만 pip install 을 돌렸다. 해시 비교로 수정, 운영에서 3방향 반증.
- 과금은 Deepgram 실측(metadata.duration), 로컬 측정은 게이트용. 업로드 게이트는 **fail-closed**.
- 운영 실사용에서 **상태값 사고** 발각 — `ended` 를 썼는데 규약은 `completed` 라 목록엔 "대기",
  상세엔 "녹음 이어하기 / 음성 노트 종료" 버튼이 떴다.

**모바일 긴 제목 잘림 (Irene 신고) — 배포됨**

  제목 칸이 **0px**(폭 15px / 높이 202px).
