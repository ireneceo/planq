## ⚠️ 이번 세션에서 배운 것 (재발 방지)

1. **★ 백엔드만 고치면 화면은 그대로 거짓말한다.** 구독 화면 면제 반영을 백엔드만 하고
   프론트를 안 만들어, 집계에서만 빠지고 행에는 "강등됨" 이 그대로 떴다. 기능은 **수신부까지**다.
2. **★ 엉뚱한 API 를 고치고 다 됐다고 착각할 수 있다.** 워크스페이스 전환기는 `/api/businesses` 가
   아니라 login·me 응답의 `user.workspaces` 를 쓴다. **어느 데이터가 그 화면을 그리는지 확인하고 고칠 것.**
3. **★ "배선했다" 는 실행으로 증명한다.** `notifyExemptExpiring` 을 cron 에 편입했다고 보고했으나
   치환이 안 먹었고 확인하지 않았다. 함수 단독 테스트 통과 ≠ 배선됨.
4. **★ 없는 컬럼 참조는 catch 가 삼킨다.** 한 세션에 3건. → `schemacol` 가드 신설.
5. **★ 가드는 만들고 나서 깨뜨려 확인한다.** 처음 짠 가드가 한 줄 다중 키를 놓쳤고,
   모델 파일 기준이라 30건 오탐이었다. 두 번 다 반증에서 발견.
6. **★ 베이스라인 전체 `--update-baseline` 은 무관한 파일까지 완화한다** — 이번에 godfile 11개가
   한꺼번에 올라갔다. 백업 후 **이번 변경분 키만 손으로** 반영할 것(이번 세션 순변화: 전부 조임, 완화 0).
7. **★ 추론으로 사용자 상태를 정하지 말 것.** 가입 후 trial 만료를 보고 "테스터겠거니" 백필했다가
   지적받고 제거. 실고객이 조용히 무료가 되면 되돌리는 쪽이 더 큰 사고다.
8. **★ 삭제는 목록에서 사라지는 것까지가 기능.** 접근만 막으면 "보이는데 안 열리는" 더 나쁜 상태.
