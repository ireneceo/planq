## 이번 세션에서 배운 것 (반복 방지)

- **화면에 안 보이는 것과 응답에 안 실리는 것은 다르다.** `content` 만 비운 코드가 번역 캐시로
  본문을 내보냈다. 가릴 땐 **지울 것을 열거하지 말고 남길 것만 남긴다(화이트리스트).**
- **필드 하나만 보는 검증은 통과한다.** 원문 표식을 심고 **응답 raw 를 통째로 스캔** + **양성 대조군**.
- **가리는 처리는 표시명·후처리를 다 적용한 뒤에.** 순서가 뒤집히면 다른 필드가 죽는다.
- **거짓 FAIL 은 판정 기계부터 의심.** e2e 가 빨간 불이었는데 실은 로그 디렉터리가 없어 **안 돌았다.**
- **감시 루프는 자기를 센다.** `pgrep -f "vite build"` 가 자기 명령줄과 일치해 영원히 안 끝났다.
- **알림의 exit 0 은 래퍼 값일 수 있다.** 빌드는 143 이었는데 완료 알림은 0 이었다 — 로그의 실 종료코드를 본다.
- **공용 컴포넌트를 찾기 전에 만들지 않는다.** 오류 화면 손잡이는 이미 `DetailFallback` 에 있었다.
